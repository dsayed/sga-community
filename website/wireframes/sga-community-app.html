Current site issues

  • Login is a generic Wix modal — no SGA branding, white background, "Log In" heading
  • Only shows Google/Facebook/Email options — no visual connection to the community
  • Modal can be accidentally dismissed, sending user back to the homepage
  • No tagline or mission statement — missed opportunity to reinforce volunteer identity

Branded header with mission

The blue gradient header with paw icon and tagline creates an emotional connection before the user even types their password. It reminds fosters why they're here: "The right dog for the right home."

Engagement

Full-screen login (not a modal)

A dedicated login screen instead of a dismissible modal. Can't be accidentally closed. The warm-white form card with rounded top corners creates a native app feel. The "Welcome back" text is personal, not transactional.

UX Priority

Social login as secondary option

Email/password is primary (most fosters signed up with email). Google and Facebook are secondary "or continue with" options below. The current site shows Google and Facebook as the primary options with email as an afterthought.

Current site issues

  • Full-viewport hero image wastes screen space — users must scroll past it every visit
  • No personalization — generic "COMMUNITY" heading, no user context
  • Forum posts shown in tiny 3-column grid — unreadable on mobile
  • Resources section uses identical calendar icons for all 6 links — no visual differentiation
  • No urgency hierarchy — critical foster needs buried alongside blog posts

Compact top bar with notifications

Replaces the desktop nav + huge hero banner. The blue bar stays brand-consistent but only uses ~48px of vertical space. Bell icon with orange dot surfaces new forum activity immediately.

Mobile UX

Personalized welcome

Greets the user by first name with their avatar. Creates an immediate sense of belonging — critical for volunteer retention. The current site shows a generic "COMMUNITY" heading with no personalization.

Engagement

Urgent needs banner

The single most important element for SGA's operations. Foster and volunteer needs get a visually distinct red-tinted card that can't be missed. Currently these are orange alert bars that look like cookie notices.

UX Priority

Quick action cards with live status

Three thumb-friendly tap targets replace the 6 identical-icon link list. Each shows contextual info: training progress (3/5 done), resource count, and new forum post count. This gives users a reason to tap.

Engagement

Feed-style recent activity

Forum posts are shown as a vertical feed with author avatars, role badges, and engagement counts — matching the mental model of social apps fosters already use. The current 3-column card grid is replaced with a scannable list.

Mobile UX

Bottom tab navigation

Five persistent tabs reachable by thumb. Replaces the desktop top-nav that requires a "More" dropdown on mobile. The current Wix hamburger menu hides key sections — the tab bar keeps them one tap away at all times.

Current site issues

  • 5 forum categories each shown as a large image card — requires scrolling through ~800px of images before seeing any posts
  • Category descriptions only visible after scrolling past the images
  • "New Posts" section shows only 3 posts in a tiny horizontal card row
  • Post previews are truncated to title only — no content preview
  • No unread/new indicators — can't tell what's changed since last visit

Page title in top bar

Clear context of where you are. The current site repeats the full "SAVING GREAT ANIMALS" branding on every page — space better used for content on mobile.

Mobile UX

Horizontal category pills with badge counts

All 5 forum categories accessible in a single horizontal scroll row using only ~40px of height. The "Urgent" pill shows a red badge count for unread needs. This replaces the 800px of category image cards.

UX Priority

Prominent new post button

Full-width orange button is immediately visible and reachable. Currently, "Create New Post" is a small outlined button above the category grid — easy to miss on mobile.

Engagement

Social-feed post cards

Each post shows: author avatar with role badge, category label, title, content preview (2 lines), optional photo, and engagement counts. This mirrors the familiar social feed pattern (Facebook/Instagram) that fosters already use daily.

Engagement

Inline images and engagement

Post images display inline in the feed rather than requiring a click-through. Like/comment/view counts are visible at a glance. The current site hides image previews and shows reactions as tiny icons with no labels.

Current site issues

  • Training courses listed as 5 bullet points — no interactivity, no progress tracking
  • Single "Access Foster Training Basics" button links to external Wix course tool
  • No visual indication of which modules are complete or where user left off
  • Training page is 70% decorative content (hero, stock photo, pictured pup story)
  • Pack Walk events listed as plain text boxes with dates — no calendar integration

Overall progress card

Immediately shows "3 of 5 complete" with a visual progress bar. This creates a completion incentive — fosters can see exactly where they stand. The current site has zero progress visibility.

Engagement

Sequential module cards with status

Each module shows its number, title, description, step count, and status (Done/In Progress/Not Started). Color-coded left thumbnails give instant visual scanning. The numbered sequence creates a clear learning path.

UX Priority

Completed modules stay visible

Green checkmarks on completed modules provide a sense of accomplishment. The completion date is shown for record-keeping. Fosters can revisit any completed module for reference.

Engagement

Current module highlighted

The in-progress module (Decompression) has an orange border to draw the eye. Shows "On step 3" so users can resume exactly where they left off — no hunting through content.

UX Priority

Behavioral support CTA

The "Request Behavioral Support" link from the current site becomes a prominent, friendly card integrated into the training flow. It's contextually placed where a foster might realize they need help — right after the training content.

Current site issues

  • Training content lives inside Wix's built-in "Online Programs" — separate UI that feels disconnected
  • No step-by-step progress indicator within a module
  • Video content and text content presented identically — no visual distinction
  • No "pick up where you left off" — users must manually find their last step

Contextual back navigation

Back arrow + module title provides clear wayfinding. The "Step 3 of 7" label gives positioning context. Users always know exactly where they are in the curriculum.

UX Priority

Visual step progress bar

Segmented progress dots show completed (green), current (orange), and remaining (gray) steps at a glance. This tiny element adds strong completion motivation — the visual "filling in" triggers reward psychology.

Engagement

Media-first content layout

Video content gets a dedicated player area at the top, followed by the written lesson. The current site presents video and text identically as plain content blocks. The visual hierarchy here signals "watch first, then read."

UX Priority

Fixed bottom navigation

Back/Next buttons are always visible at the bottom of the screen — no scrolling to find navigation. The primary action (Next) uses the orange brand color to draw the eye. On the final step, this becomes "Mark as Complete."

Current site issues

  • No search — fosters must visually scan a 3-column grid of 12+ topic cards to find what they need
  • Topic cards show only the title and "See resources" link — no content count or type info
  • All cards use identical styling regardless of whether they contain videos, articles, or links
  • Categories (Training, Health, Foster, Volunteer, Other) are separated by section headings but the sections look identical
  • Library page is one of the longest pages — requires extensive scrolling on mobile

Full-text search

Top-of-page search bar lets fosters type a question like "crate training puppy" and immediately find relevant resources. The current library has no search at all — a major gap when fosters need quick answers during a crisis.

UX Priority

Category filter chips

Horizontal scroll chips filter the library by top-level category. "All Topics" shows everything; selecting "Dog Training" shows only training resources. This replaces scrolling past multiple headed sections.

Mobile UX

Resource type indicators

Each topic card now shows a colored icon indicating the primary content type: green for video, blue for articles, gray for external links. The count ("3 videos, 2 articles") tells fosters what's inside before tapping.

UX Priority

Compact list layout

Horizontal resource cards use much less vertical space than the current 3-column bordered grid (which collapses to 1 column on mobile). A foster can see 5+ topics per screen instead of 2-3.
