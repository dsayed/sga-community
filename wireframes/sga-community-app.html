Design Decisions

Bottom Tab Bar

Five core sections always one tap away. No hamburger menus, no hunting. This is the single biggest UX upgrade over the Wix site.

Quick Action Tiles

Training, Library, Forums, Directory visible immediately on launch. No scrolling to find them — the #1 complaint about the current site.

Urgent Needs Banner

Push notifications + in-app banner for time-sensitive volunteer/foster requests. This is what turns a passive website into an active coordination tool.

Low-Friction Posting

"What's happening with your foster?" prompt + photo/camera buttons. The current forum has 0 member-generated posts — this encourages sharing.

Category Tabs

Horizontal scrollable tabs keep all 5 forum categories one tap away. The current site requires navigating to a separate page to find categories.

Progress Tracking

Members see exactly where they are in training. The current site links to Google Forms with no tracking. This builds completion motivation.

In-App Courses

Videos, text, and interactive content hosted inside the app — not linking out to Google Forms. Members stay in the experience.

Search-First

A foster at 10pm with a barking dog needs to find "barking" resources instantly. Search is front and center, not buried.

Category Filters

Preserves the current site's excellent library structure but makes it horizontally scrollable and tappable rather than a long page scroll.

Role Filters

"Show me fosters in Bellevue" or "find a volunteer" — the current directory is just a flat grid with no way to filter by role or location.

Actionable Cards

Each member card shows role, location, and a direct message button. The current directory only shows follow counts which aren't useful.

Key Recommendations

  • Bottom tab bar with 5 core sections — Home, Forums, Training, Library, People. Every feature is always one tap away. This is the single biggest improvement over the current site where features are hidden in menus.
  • Urgent needs banner with push notifications — Time-sensitive foster/volunteer requests appear as a persistent banner + push notification. This transforms a passive website into an active coordination tool.
  • In-app training with progress tracking — Courses hosted natively with video, text, and completion status. No more linking out to Google Forms. Members see exactly where they are.
  • Search-first library — A foster at 10pm with a barking problem needs to find "barking" resources instantly. Full-text search is front and center, with category filters preserving the current site's excellent library structure.
  • Low-friction posting in forums — "What's happening with your foster?" prompt with camera/photo buttons encourages member-generated content. The current forums have near-zero member posts because posting requires too many steps.
  • Filterable member directory — Role tags (foster, volunteer, adopter, staff), location, and direct message buttons. "Show me fosters near me" is a real use case the current flat grid can't serve.
  • Same codebase, responsive on desktop — Sidebar navigation on desktop, bottom tabs on mobile. One app that works everywhere. Built as a PWA (Progressive Web App) so it's installable on phones without the App Store.
